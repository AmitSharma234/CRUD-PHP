# 📘 PHP CRUD (Create, Read, Update, Delete) with MySQL

A complete learning repository that explains **PHP CRUD operations step by step** using **PHP & MySQL**.  
This project is designed to teach **database-driven web development fundamentals** in a simple, practical, and professional way.

---

## 🚀 Project Objective

- Understand **CRUD operations** in PHP
- Learn **database connectivity** using MySQL
- Perform **Create, Read, Update, Delete** operations securely
- Follow **clean code and best practices**
- Build a **real-world PHP database application**

---

## 🧠 What You Will Learn

- PHP & MySQL integration
- SQL basics (INSERT,SELECT,UPDATE,DELETE)
- Form handling using PHP
- GET and POST methods
- Prepared statements 
- Validation & error handling
- Project File Structure 
---

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, Bootstrap
- **Backend:** PHP 8+
- **Database:** MySQL 
- **Server:** Apache (XAMPP)
